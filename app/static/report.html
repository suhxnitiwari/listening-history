      How this was made

      • Extract: Python reads Spotify's extended streaming history export.
      • Transform: songs only, Austin time, duplicates and overnight loops removed, one song under many IDs merged.
      • Load: a star schema in PostgreSQL, one fact table of plays and five dimensions.
      • Ask: SQL views with CTEs and window functions, served by FastAPI.
