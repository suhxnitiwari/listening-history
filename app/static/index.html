          How it's built

          From a zip file to this page

          1. ExtractPython reads every file in Spotify's export.
          2. TransformSongs only, Austin time, duplicates merged, overnight loops removed, and my IP address and location dropped.
          3. LoadA star schema in PostgreSQL on Neon: one fact table of plays, five dimensions.
          4. AskSQL views with window functions, CTEs and gaps and islands.
          5. ServeA FastAPI server, one endpoint per question, with song previews from the iTunes Search API.
